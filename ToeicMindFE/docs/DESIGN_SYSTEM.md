# Quy chuẩn giao diện ToeicMind

Tài liệu chuẩn dùng chung cho ToeicMindFE và ToeicMindAdmin nằm tại:

**[ToeicMindAdmin/docs/DESIGN_SYSTEM.md](../../ToeicMindAdmin/docs/DESIGN_SYSTEM.md)**

Đọc tài liệu đó trước khi phát triển giao diện tiếp theo. Đây là nguồn thống nhất về màu sắc, font, khoảng cách, bố cục, component, trạng thái form, responsive và khả năng tiếp cận; cập nhật bản chuẩn khi thay đổi quy ước.

Mã giao diện được giữ ở từng ứng dụng để build độc lập. Đồng bộ các token/component chung vào cả hai frontend, không import mã từ repository bên cạnh. Chi tiết API xác thực của FE nằm trong [AUTH_INTEGRATION.md](AUTH_INTEGRATION.md).
